THE SAATH CAMPAIGN — WEBSITE DESIGN & BUILD PROMPT

Create a complete, polished, responsive website for The Saath Campaign, a teen/student-led organisation that works to provide underprivileged children with practical education and basic life skills that can help them build stronger futures.

The website must feel like a real youth-led social initiative with a strong editorial design identity.

IMPORTANT: Do NOT design this as a conventional corporate NGO website.

The visual identity should be based heavily on the attached Saath Campaign Instagram post and colour-palette references.

The website should feel like the website version of the Saath Instagram feed.

⸻

1. CORE BRAND PERSONALITY

The design should communicate:

* Youth-led
* Bold
* Thoughtful
* Human
* Creative
* Slightly unconventional
* Educational
* Community-focused
* Authentic
* Optimistic
* Socially conscious

The overall feeling should be:

“A group of teenagers decided that something needed to change, so they built something themselves.”

It should feel confident without becoming corporate.

Avoid generic:

* Blue-and-white NGO layouts
* Corporate cards
* Generic stock illustrations
* Overly rounded SaaS-style UI
* Excessive gradients
* Generic charity website templates
* Excessively polished corporate aesthetics

Instead, use the visual language of the attached social media post.

⸻

2. ATTACHED VISUAL REFERENCES

The attached images are the primary visual references.

The first reference shows the existing Saath Campaign social-media design language.

The second reference shows the official Saath colour palette.

Use them as visual references rather than treating them as content that needs to be reproduced literally.

The website should preserve the same design DNA.

4. VISUAL LANGUAGE

The website should directly borrow the visual principles seen in the Saath post.

Typography

Use a strong contrast between:

Bold display typography

For major words and statements.

Large, heavy, uppercase typography similar to the:

“THIS IS”

treatment in the reference.

Elegant serif typography

Use a large expressive serif/italic style for important words, similar to:

“saath.”

in the reference.

This combination should become one of the defining features of the website.

Do not make every heading look identical.

Some headings can use:

* Bold uppercase sans-serif
* Large serif italic
* Mixed typography within one heading

For example:

THIS IS

saath.

Use the supplied Saath font if provided separately. If the exact font is not supplied, choose fonts that recreate this same bold-sans + elegant-serif editorial contrast.

5. COLLAGE / EDITORIAL DESIGN

Use subtle collage elements throughout the website.

Possible elements include:

* Torn paper edges
* Paper textures
* Hand-drawn circles
* Rough underlines
* Sketch-like arrows
* Scribbled annotations
* Tape-like image attachments
* Slightly irregular borders
* Newspaper/editorial layouts
* Black-and-white cutout photography
* Layered images
* Overlapping text and imagery
* Grid-paper textures
* Handwritten-style annotations

These elements should feel intentional and artistic.

Do not overuse them.

The goal is:

Editorial magazine + student campaign + handmade collage

rather than:

Corporate NGO website + random decorations.

7. SPACING & LAYOUT

Use generous whitespace.

Do not fill every part of the screen.

Use an editorial grid.

Desktop:

* Wide margins
* Large typography
* Asymmetric layouts
* 12-column grid where appropriate

Mobile:

* 20–24px side margins
* Single-column layouts where necessary
* Large typography maintained but scaled appropriately

Sections should have clear visual separation.

⸻

8. IMAGERY

5. Events
6. Behind-the-scenes

Avoid generic stock photographs.

Black-and-white imagery can be used in places where it fits the existing Instagram aesthetic.

Images can be combined with the warm cream background and dark navy typography.

⸻

10. RESPONSIVENESS

The website must be fully responsive.

Desktop:

* Large hero
* Editorial multi-column layouts
* Large statistics
* Image collages

Tablet:

* Reduce columns
* Preserve typography hierarchy

Mobile:

* Hamburger navigation
* Stacked layouts
* Full-width imagery
* 1–2 column statistics
* Properly scaled typography
* No horizontal scrolling
* Collage elements must remain readable

Do not simply shrink the desktop design.

Recompose layouts for mobile.

⸻

11. INTERACTION

Keep interaction sophisticated but subtle.

Use:

* Smooth hover states
* Small image zoom on hover
* Underline animations
* Subtle transitions
* Scroll-based reveal animations

Avoid excessive animations.

The site should feel calm and editorial.

⸻

12. MOST IMPORTANT DESIGN RULE

When making design decisions, always ask:

“Would this look like it belongs next to the Saath Instagram post?”

If the answer is no, redesign it.

The website should NOT look like a generic NGO template.

It should look like:

THE SAATH CAMPAIGN — turned into a website.

The attached Instagram post is the strongest visual reference.

The attached colour palette is the official colour system.

The supplied typography should be preserved.

The final website should feel like a young, rebellious, thoughtful and creative student-led campaign that takes its work seriously without looking corporate.
